# RAZIEL · identidad visual / visual identity

RAZIEL es el nuevo nombre elegido por Sebastián para RadioWorkbench, junto a PAIMON y METATRON. El identificador interno `cl.sebastian.RadioWorkbench` y la dirección del repositorio se conservan para mantener datos, preferencias, perfiles y el canal de actualización. La versión 0.17.0/build 33 adopta RAZIEL como nombre visible; RadioWorkbench se mantiene como nombre histórico del proyecto y en las rutas técnicas que dan continuidad a la aplicación.

El icono propio combina una antena, dos arcos de recepción y una onda. La versión aprobada como dirección usa blanco y negro, geometría simple y sin volumen metálico, siguiendo la familia visual de METATRON sin copiar su cubo. El concepto se creó con generación de imágenes y se refinó con el icono público de METATRON como referencia de estilo. El PNG fuente está en `Sources/RadioWorkbench/Resources/Brand/RazielIcon.png`.

`script/make_brand.swift` produce los tamaños macOS, ICNS, icono de documentación, portada bilingüe y tres símbolos SVG geométricos. Conserva el original. Los iconos funcionales de la interfaz usan SF Symbols del sistema; no se incorpora una biblioteca externa ni recursos de aplicaciones comerciales. La portada es identidad gráfica, no una captura de una señal RF recibida.

Ajustes ofrece cuatro paletas: Grafito (predeterminada), Petróleo, Bosque y Ámbar. Solo cambian acentos de controles, con variantes claro/oscuro; se conservan superficies semánticas del sistema y colores de avisos. Las tres paletas del waterfall siguen siendo independientes. El icono permanece monocromo.

**Creado por Sebastián Pastén F.**

RAZIEL is the new name selected by Sebastián for RadioWorkbench, alongside PAIMON and METATRON. The internal bundle identifier `cl.sebastian.RadioWorkbench` and repository URL remain unchanged to preserve data, preferences, profiles and update continuity. Version 0.17.0/build 33 uses RAZIEL as its display name; RadioWorkbench remains the project's former name and is retained in technical paths that preserve application continuity.

The monochrome mark combines an antenna, reception arcs and a wave. Image generation was used for the concept, then refined using the user's METATRON icon as a style reference. The generator creates macOS icon sizes, ICNS and documentation graphics without changing the source PNG. Functional app icons remain native SF Symbols. The cover is branding, not an RF reception screenshot.

Four persistent light/dark palettes change control accents: Graphite, Petroleum, Forest and Amber. Semantic surfaces and warning colors remain native; waterfall palettes are independent. The app icon stays black and white.
